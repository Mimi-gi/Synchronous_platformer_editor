# Synchronous Platformer Editor

LDtk-like 2D platformer editor with realtime multiplayer editing.

## Direction

- Web app first
- React + TypeScript + Vite for the application shell and tool UI
- WebGPU-first renderer behind a renderer interface
- Canvas2D fallback for early development and unsupported browsers
- Collaboration layer will be added separately from rendering

## Development

```bash
npm install
npm run dev
```
